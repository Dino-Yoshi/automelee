# Auto Melee

A small client-side Forge mod for Minecraft 1.12.2. Hold the attack
button with a sword or axe in your main hand and it keeps attacking
whatever living thing you're aiming at, swinging each time the attack
cooldown is full.

Timing matches a perfectly timed click, so damage per second doesn't
change. When RLCombat is installed, attacks go through its main-hand
attack; otherwise the vanilla attack is used. Targeting follows
ReachFix when it's present.

There is no config, keybind or HUD. Drop the jar in `mods/` and it
works. Servers don't need it.
